# Hwang's Tools

Kumpulan tools pribadi untuk keperluan Letterboxd. Semua berjalan di browser (client-side), tanpa backend.

## Daftar Tools

| Tool | Deskripsi | URL |
|---|---|---|
| **Monthly Calendar** | Buat kalender bulanan estetik dari file ZIP Letterboxd | `/movie-calendar/` |
| **Custom Posters** | Generator template poster ulasan film siap post ke medsos | `/custom-posters/` |
| **Movie Collage** | Buat kolase poster film bertema bebas dengan judul kustom | `/movie-collage/` |
| **Year in Review** | Rangkuman statistik tahunan film yang telah ditonton | `/year-in-review/` |

## Cara Pakai

1. Buka landing page (`/`)
2. Pilih salah satu tool dari menu
3. Ikuti instruksi di halaman tool masing-masing

> **Catatan:** Semua tool hanya bisa diakses via **desktop** (komputer/laptop). Menggunakan tablet atau HP akan memunculkan pesan "Hanya Tersedia di Desktop".
